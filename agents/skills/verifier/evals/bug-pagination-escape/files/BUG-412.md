# BUG-412: Evidence sync stops early for some accounts

Reported by support: a few accounts only ever show the first batch of
resources from the vendor API. Re-running the sync doesn't help.

Root cause: the vendor API sometimes returns an empty page that still has a
`nextToken` (it filters items after paginating). `fetchAll` treated an empty
page as the end of data and stopped.

Fixed in PR #233 — see `fix.diff`. Deployed Tuesday; first reported 9 days
after the regression shipped.
